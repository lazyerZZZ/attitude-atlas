Frame guide & conversion math

PX4 uses forward, right, down for the body and north, east, down for the world. ROS uses forward, left, up for the body and east, north, up for a geographic local world frame. Both rows describe how to express a body vector in world coordinates.

In matrix form, R_ros = A · R_px4 · B, where A(n,e,d) = (e,n,−d) changes the world basis and B(f,l,u) = (f,−l,−u) changes the body basis. Quaternion component order also changes. A quaternion and its negative describe the same attitude.

Try “Level, facing north”. PX4 reads [1, 0, 0, 0] and ROS reads [0, 0, 0.707107, 0.707107]. The aircraft points north in both frames. At vertical pitch, multiple roll/yaw pairs describe the same attitude.
